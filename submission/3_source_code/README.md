# Source code

Repository: https://github.com/Pranav0774/energy-conservation-game

The repository is private. If a grader cannot open it, use `source_code.zip` in this folder (the working tree at the time the submission was assembled, without git history).

Run the game:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Run the tests: `python -m pip install -r requirements-dev.txt` then `python -m pytest`. See the top-level README for the layout.
